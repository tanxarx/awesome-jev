# Awesome Jev [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of resources, open-source clones, integrations, and engineering playbooks for **Jev** — TypeSafe AI's non-generative "System 1" decision model.

Jev doesn't generate text. Given a prompt and a set of typed candidates (a choice, a score, a yes/no), it returns a calibrated probability over the candidates in a single forward pass — no sampling, no JSON parsing, no hallucinated options. Since its release, a fast-moving ecosystem of integrations, open-source reproductions, and "System 1 / System 2" agent-architecture patterns has grown up around it. This list tracks it.

Every link below was resolved from its original source tweet/thread and verified to be a live, matching repository at the time it was added — see [CONTRIBUTING.md](CONTRIBUTING.md) for how entries are checked.

## About Jev

- [typesafe.ai](https://typesafe.ai) - TypeSafe AI's homepage.

- [InfoQ — TypeSafe AI Releases Jev](https://www.infoq.com/news/2026/10/typesafe-ai-jev-released/) - News write-up of the release of Jev as a decision-only model that returns typed probabilities instead of text.
- [The Information — Jev Fervor Leads to Talk of Big Valuation Boost](https://www.theinformation.com/newsletters/dealmaker/jev-fervor-leads-talk-big-valuation-boost) - Reports TypeSafe AI is in talks with investors to raise $1 billion or more at a valuation above $10 billion.

- [typesafe.ai/blog/series-ai](https://typesafe.ai/blog/series-ai) - TypeSafe's Series A announcement: $870 million at a $7.5B valuation, led by Andreessen Horowitz with Sequoia Capital and DCVC participating.

## Open-Source Reproductions & Clones

- [bespokelabsai/nimble](https://github.com/bespokelabsai/nimble) - "Bespoke Nimble": a 9B open reproduction on Qwen3.5, built in a day from 2,676 examples via LoRA. Trained with "contrastive data curation" (near-identical question pairs with one flipped fact) to teach evidence-reading over explanation-generation. Scored 90.12% vs. Jev's 93.21% on the team's own eval. Its README adds Nimble-v4 (9B) and Nimble-v4-max (27B), launched October 13 on Bespoke's API, with v4-max at 68.46 against Jev 1.13's 57.96 on the Decision Index public suite in the team's own run.
- [NandhaKishorM/laya](https://github.com/NandhaKishorM/laya) - Laya, the upstream Apache-2.0 Jev alternative: an RLCD-trained decision engine shipped as a PyPI package, later ported to Apple Silicon as laya-mlx below.
- [convaiinnovations/laya](https://huggingface.co/convaiinnovations/laya) - Laya's model weights on Hugging Face.
- [mizorewww/laya-mlx](https://github.com/mizorewww/laya-mlx) - Laya (an Apache-2.0 Jev alternative) ported to Apple Silicon via MLX: 60 decisions/sec at under 1GB RAM, demoed playing Snake from raw probability classification.
- [Heman10x-NGU/Verdict-open-jev](https://github.com/Heman10x-NGU/Verdict-open-jev) - "Verdict": a 151M-parameter ModernBERT + GLiClass head model returning calibrated probabilities and an explicit "insufficient evidence" outcome in one forward pass. Weights on [Hugging Face](https://huggingface.co/heman10x/rlcd-modernbert-151m).
- [Heman10x-NGU/openJev-verdict-2.0](https://github.com/Heman10x-NGU/openJev-verdict-2.0) - v1.4 inference-engine fixes for the 151M Verdict model (calibrator auto-loading, NLI-style candidate templating, a 512-token context cap) that raised its public JevBench score from 66.2 to 74.9, plus a newer "Verdict 2.0" architecture and an in-browser WebGPU engine.
- [jaredpalmer/kev](https://github.com/jaredpalmer/kev) - A tiny Jev-like model built on Qwen2.5-0.5B, trainable and runnable locally on a MacBook.
- [TianyuCodings/NanoJev](https://github.com/TianyuCodings/NanoJev) - Independent implementation: a Qwen3-0.6B parallel judgment model with public weights and training code.
- [logan-markewich/jeff](https://github.com/logan-markewich/jeff) - A self-hosted drop-in replacement for Jev, powered by GliFormer.
- [hr98w/jev-visual](https://github.com/hr98w/jev-visual) - An educational Jev-like visual-inference experiment on Apple Silicon, adding image input which Jev lacks.
- [ikermoel/open-alternative-jev](https://github.com/ikermoel/open-alternative-jev) - An open-source System-One-style decision layer over any open-weights LLM, benchmarked against Jev.
- [kshetrajna12/reflex](https://github.com/kshetrajna12/reflex) - A small open decision model on Qwen3.5 re-creating the Jev/System One API with vision input.
- [ekzhang/openjev-sglang](https://github.com/ekzhang/openjev-sglang) - A Jev-compatible API endpoint built on open models via SGLang (prefill-only), for self-hosting on GPU servers.
- [githubnext/localjev](https://github.com/githubnext/localjev) - A local Jev-compatible `/v1/systemone` bridge backed by DiffusionGemma.
- [TheoLeeCJ/SemIf](https://github.com/TheoLeeCJ/SemIf) - "Semantic ifs" from open models running on a single 3090 at home. Independent research, not affiliated with Jev/TypeSafe.
- [vinnylarouge/jevlike](https://github.com/vinnylarouge/jevlike) - Independent research evaluating mixed-length candidate sets as a Jev-style research baseline, not a drop-in clone.
- [sabeel111/OpenSourceJev](https://github.com/sabeel111/OpenSourceJev) - Independent research and experiments on small decision models, inference optimization, and parallel sampling in the Jev style.
- [razorback16/openjev](https://github.com/razorback16/openjev) - An independent Jev-compatible System One decision server running DiffusionGemma via vLLM or on-device MLX.
- [abhishek085/open-spark-jev](https://github.com/abhishek085/open-spark-jev) - Open-source local decision models inspired by Jev/System One, built on Qwen3 and tuned for NVIDIA DGX Spark hardware.
- [fidecastro/jevify](https://github.com/fidecastro/jevify) - A pip-installable adapter that serves any OpenAI-compatible LLM (including local GGUFs) as a Jev-like typed-decision endpoint.
- [TimothyZhang7/open-decisions](https://github.com/TimothyZhang7/open-decisions) - An MIT Python SDK for typed decisions from local open models, benchmarked against Jev on an experimental Tetris demo.
- [vllm-project/vllm#57250](https://github.com/vllm-project/vllm/pull/57250) - A vLLM patch exposing Google's DiffusionGemma (26B MoE, 3.8B active) behind a Jev-compatible `/v1/systemone` endpoint, using parallel denoising instead of autoregressive generation and adding image input, which Jev lacks; [v0.32.0](https://github.com/vllm-project/vllm/releases/tag/v0.32.0) then serves `/v1/systemone` by default for choice, noul, and score questions, also on Cloudflare/clef-omni and LiquidAI/d1-3B, documented under [Structured Decisions Models](https://github.com/vllm-project/vllm/blob/main/docs/models/structured_decisions_models.md).

- [wnzn/semif-go](https://github.com/wnzn/semif-go) - A Jev-like decision API server over local llama.cpp models, answering choice/yes-no/score questions on text or images without generating JSON; built on the scorer from TheoLeeCJ/SemIf above.
- [Mapika/decider-2b](https://huggingface.co/Mapika/decider-2b) - An Apache-2.0 2B-parameter Jev-style decision model on Qwen3.5, with a vision variant and a GGUF quantization; over 130k combined downloads on Hugging Face.
- [wfzyx/von](https://github.com/wfzyx/von) - An Open-Source, Non-Autoregressive System One Decision Model. Calibrated discrete, probabilistic, and ordinal inference in sub-25ms.
- [Contrastive-LM/CLM](https://github.com/Contrastive-LM/CLM) - Contrastive Language Models: a System One model that embeds states and actions separately and matches them by similarity instead of answering typed questions, reporting on-par accuracy with Jev at up to 9x lower latency.
- [togethercomputer/tev1](https://github.com/togethercomputer/tev1) - Together AI's open-weight reproduction: Qwen3.5-4B fine-tuned via LoRA on ~38K examples to pick one answer letter from 2-24 options, released with the full data recipe and a $17 training-cost writeup.
- [fastino/GLiNER2.5-Decide](https://huggingface.co/fastino/GLiNER2.5-Decide) - Fastino Labs' 340M-parameter Apache-2.0 encoder decision model; scored 60.1% on their own Fast Decisions benchmark, ahead of Laya (46.6%) and a Jev-based baseline (57.5%).
- [SupersonicLabs/Julia-1](https://huggingface.co/SupersonicLabs/Julia-1) - A 144M-parameter Apache-2.0 decision model on mmBERT-small; runs on CPU, scores 73.15% on Jev's own Typed Decisions benchmark, with a WebGPU ONNX build for in-browser inference.

- [Remek/basal-1.0-4.5B](https://huggingface.co/Remek/basal-1.0-4.5B) - A Polish/English typed-decision model on Bielik-4.5B, inspired by Jev and returning a calibrated probability per allowed answer in one forward pass; the [rkinas/basal](https://github.com/rkinas/basal) inference engine is listed on its card.
- [PostHog/jeeves](https://huggingface.co/PostHog/jeeves) - Jeeves-9B: an Apache-2.0 Jev-like decision model on Qwen3.5-9B with a pointer head that writes a reasoning chain per question before returning calibrated probabilities.

- [TokenRhythm/NeoHorse-Jev-4B](https://huggingface.co/TokenRhythm/NeoHorse-Jev-4B) - An Apache-2.0 4B open decision model that turns app states into structured decisions with probabilities, also published on ModelScope.
- [caiovicentino1/Eikos-27B](https://huggingface.co/caiovicentino1/Eikos-27B) - An open 27B Jev-like decision model with a 4B sibling and quantized builds, evaluated against Jev and Laya on JevBench (official runs requested).
- [avbiswas/bev-decider-0.4B](https://huggingface.co/avbiswas/bev-decider-0.4B) - A 0.4B Jev-compatible decision model that is invariant to option order by construction; 74.7% vs. Jev 1.13's 78.0% on 5,000 held-out questions.

- [firelex/jeff](https://github.com/firelex/jeff) - A 0.8B open "System 1" decision model with swappable LoRA adapters on one base, using the same request format as Jev; unaffiliated, and distinct from logan-markewich/jeff above.

- [TheREZOR/TinyDecide](https://huggingface.co/TheREZOR/TinyDecide) - A 10.4M-parameter, 4-bit Apache-2.0 Jev-style decision model on ELECTRA-small that answers several typed questions in one encoder pass and runs on an ESP32-S3 microcontroller.

- [mohit67890/imajev](https://github.com/mohit67890/imajev) - An open Jev-style typed-decision model that also takes images: a photo, app state, and typed questions go in and probabilities come out locally, with optional temperature calibration.

- [eullm/eullm](https://github.com/eullm/eullm) - An AGPL Rust engine for running EU-compliant models locally that adds a `/v1/systemone` decisions endpoint and a "Jev-Style" 2B model, reporting 64 questions about one page in 0.66 s on an RTX 5070 Ti.
- [FrontiersMind/Lumma-fev-27B](https://huggingface.co/FrontiersMind/Lumma-fev-27B) - A full-weight Qwen3.8-27B fine-tune answering typed questions in English, Hindi, Tamil and Kannada behind the same `/v1/systemone` contract; its [launch post](https://huggingface.co/blog/FrontiersMind/lumma-fev-27b) reports 90.7% versus Jev's 83.9% on 4,454 held-out decisions in the authors' own eval.
- [respanai/span-02](https://huggingface.co/respanai/span-02) - Respan's open-weight decision model, a Gemma 4 26B-A4B fine-tune that follows TypeSafe's System One API and thinks briefly only when unsure; its card reports 63.62 on the Decision Index 0.3 public text suite and the weights need the bundled Rust/CUDA engine.

- [ibm-granite/granite-switch-4.1-8b](https://huggingface.co/ibm-granite/granite-switch-4.1-8b) - IBM's Apache-2.0 modular model serving chat, a `decision` adapter and speech from one endpoint; its [launch post](https://huggingface.co/blog/ibm-granite/granite-switch-4-1) reports the Guardian adapter beating Jev 1.13 on safety-related decision tasks in IBM's own evaluation.
- [vllm-sr/d3](https://huggingface.co/vllm-sr/d3) - vLLM Semantic Router's Apache-2.0 Decision 3.0 family: d3, a 27B multimodal decision model on Qwen3.8-27B scoring 66.3 on Jev Decision Index 0.3.2, plus [d3-lite](https://huggingface.co/vllm-sr/d3-lite) (0.85B, 32.3) and flash, mini, nano, and edge sizes in the [collection](https://huggingface.co/collections/vllm-sr/decision-30).
- [sthanika-ai/Sieve-31B](https://huggingface.co/sthanika-ai/Sieve-31B) - Sthanika's Apache-2.0 rank-128 LoRA decision adapter on Gemma 4 31B, with a full score of 63.8 on the Jev Decision Index 0.3.2 leaderboard; the Sieve family runs from 0.8B to 31B.
- [frontier-infra/jebadiah-27b-v2-1](https://huggingface.co/frontier-infra/jebadiah-27b-v2-1) - Frontier Infra's Apache-2.0 Jebadiah v2.1 decision models, 27B on Qwen3.8-27B and a [9B](https://huggingface.co/frontier-infra/jebadiah-9b-v2-1) on Qwen3.5-9B with GGUF and MLX builds, reading label-token logits for choice, noul, and score questions and scoring 55.94 and 44.91 on the Decision Index Full board.
- [TeenageWorks/Toddler-Jev](https://huggingface.co/TeenageWorks/Toddler-Jev) - ToddlerJev: an open-weight native-audio decision model that adds an 8.4M-parameter adapter and pointer head to Qwen2.5-Omni-3B to pick among candidate answers for a recording, scoring 68.70% on MMAU-mini; see the [launch post](https://teenage.works/blog/toddler-jev).
- [LiQiiiii/Jeva](https://github.com/LiQiiiii/Jeva) - Code for "Jeva: System One Models from First Principles", a decision-native architecture with a shared encoder over request and options, symmetric aggregation for permutation invariance, and an explicit null estimate, released with [Jeva-4B](https://huggingface.co/LIQIIIII/Jeva-4B) weights.
- [MCG-NJU/VideoJev](https://github.com/MCG-NJU/VideoJev) - VideoJev: a System One model for video that scores temporal intervals and answer options instead of decoding text; its Apache-2.0 4B and 35B-A3B weights report +6.7 and +10.8 mIoU over their backbones and over 100x faster video QA.

- [STAR AI — Jev hands-on (Zenn, Japanese)](https://zenn.dev/starai_org/articles/jev-system-one-review) - Builds a Japanese confidential-information checker on Jev that scores personal, business, HR, and legal sentences by severity, and tests 1.14's Box image location two days after release.
- [Oumi — How to build a decision model like Jev](https://oumi.ai/blog/how-to-build-a-decision-model-like-jev) - Walks through training, calibration, and single-pass serving for a Jev-like model, and argues from Jev's answers and token counts that it is likely Qwen3.5-35B-A3B or Qwen3.6-35B-A3B with a swapped vocabulary.
- [formations-analytics — a daily news brief with n8n (French)](https://www.formations-analytics.com/le-mag/comment-creer-une-veille-quotidienne-automatisee-avec-n8n/) - An n8n workflow that asks Jev three questions about each news article, at about $0.00004 per article, before a research model writes a sourced Slack brief only for topics that moved.
- [omiossec — Jev in cloud operations with PowerShell](https://dev.to/omiossec/decision-model-in-action-jev-in-cloud-operation-with-powershell-367c) - Calls Jev from PowerShell to judge cleaned-up Bicep WhatIf output, with every call in the article totalling 103,525 tokens for $0.0039.
- [Flowgrammer — Jev for document classification](https://flowgrammer.ca/insights/typesafe-jev-document-classification) - Treats Jev's document-type label after OCR as a routing proposal, covering what to log, confidence gates, and when to send uncertain files to a human reviewer.
- [amanoese — Jev and SAM for livestream exposure (Qiita, Japanese)](https://qiita.com/amanoese/items/67e5831a34e64bf7bae4) - Compares Jev 1.14 with SAM for catching inappropriate on-stream exposure: of 119 frames after skin appeared, SAM Agent flagged 109 and Jev 14.
- [AI Insight Journal — Jev on scam texts (Korean)](https://aiinsightjournal.com/2026/10/20/9936/) - On 12 text messages, a question about delivery scams alone missed other scams, and with a broader question a 50% threshold missed 3 of 6 scams while 30% caught all six, for about $0.0002.
- [Layer2C Labs — put the judge where code asks the question](https://labs.layer2c.com/labs/jev-gate) - In 1,000 scripted booking conversations, letting code run the dialogue and Jev read only the patient's answer let 2.1 bad bookings per 100 through, against 31.1 for the same design with an untrained Gemma reader, for about 74 cents of Jev calls.
- [beri.net — d1-ultra prices like Jev but rebills images](https://www.beri.net/article/liquid-ai-d1-ultra-decision-model-pricing-artificial-analysis-decision-index-vs-jev-decision-1-image-billing-per-question) - Liquid's d1-ultra matches Jev's $0.042 per million input tokens but bills every image again for each question, and its Decision Index lead comes from text-only tests and more abstention.
- [Vals AI — How pro-China are Chinese models?](https://www.vals.ai/blogs/china-us-analysis) - Extends the analysis to decision models, finding that Jev and others assign high probabilities to some pro-China positions on yes/no political questions.
- [Yashvardhan Goel — typographic attacks on Jev](https://frenzyscholar.substack.com/p/the-ai-saw-something-we-couldnt) - A sticker naming the wrong object changed Jev 1.14's answer in about 1 in 20 photos but lowered its score for the correct object by 8.6 points on average, and by 7.1 points when the label was very faint.
- [DAIR.AI Academy — Jev-as-a-Judge lab](https://academy.dair.ai/labs/jev-as-a-judge-for-agent-evals) - A hands-on lab that scores an agent's tool choices, execution trace, and outcomes against a rubric with Jev through OpenRouter.
- [ChaoLab — Jev's confidence under prompt injection](https://ickma2311.github.io/ChaoLab/jev-confidence-under-injection.html) - On authority-injected support tickets, Jev 1.13's hijacked decisions had higher median confidence (0.730) than resisted ones (0.570), though a 0.85 gate still rejected 171 of 247 hijacked decisions.
- [WasimJalali — Jev as a second check before hiding comments](https://x.com/WasimJalali/status/2112243632858353740) - On 867 real decisions in a live Q&A app, Gemini 3.8 Flash alone hid 7 real questions and none with a Jev check, and GPT-6 Luna 13 alone and 2 with Jev, at a 0.28 s median per Jev answer.
- [Angelinafox_AI — StartLux vs. Jev as a screening layer](https://x.com/Angelinafox_AI/status/2112650025302118804) - On 4,100 finance document links, the open StartLux-Decision 27B cut the noise reaching the frontier model by 19.68% against 3.90% for Jev under the same cutoff, with no core links wrongly removed by either.
- [hm_arora — Jev reads analog clocks](https://x.com/hm_arora/status/2112531497035141627) - On 100 random synthetic clocks Jev read 54% to the exact minute and 86% within two minutes.
- [simplifyinAI — Jev vs. GPT-5.5 as a judge](https://x.com/simplifyinAI/status/2112375973232423301) - Judging the same 100 agent trajectories took Jev 13.5 s and $0.0019 against 120.8 s and $0.42 for GPT-5.5, roughly 9x faster and 219x cheaper in that run.
